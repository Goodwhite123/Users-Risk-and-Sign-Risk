🛡️ Entra ID Identity Protection & Conditional Access
Este repositório documenta a implementação de políticas de Conditional Access no Microsoft Entra ID para mitigação automatizada de riscos de identidade (User Risk e Sign-in Risk), como credenciais vazadas e viagem impossível, integrando sinais do Identity Protection ao ambiente corporativo.

🎯 Objetivo do Projeto
O objetivo deste laboratório é demonstrar a configuração de uma arquitetura de acesso seguro baseada nos princípios de Zero Trust, garantindo a proteção das identidades e remediando ameaças em tempo real sem comprometer a disponibilidade do ambiente.

⚙️ Tecnologias e Recursos Utilizados
Microsoft Entra ID (P2)
Identity Protection: Avaliação de risco em tempo real.
Conditional Access: Políticas baseadas em risco.
Authentication Strengths: Exigência de métodos de autenticação robustos (ex: Microsoft Authenticator ou FIDO2), bloqueando métodos fracos como SMS ou Voz.
